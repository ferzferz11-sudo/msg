## КРИТИЧНЫЕ ПРОБЛЕМЫ (Must Fix)

### C1. Firebase ключ закоммичен в git
- **Файл:** `lavender-messenger-firebase-adminsdk-fbsvc-1b8ed485d7.json`
- **Проблема:** `.gitignore` имеет правило, но файл добавлен раньше. Anyone с доступом к репо получает полный Firebase Admin доступ.
- **Фикс:** `git rm --cached`, ротация ключа в Firebase Console.

### C2. `.env` закоммичен в git
- **Файл:** `.env` (tracked несмотря на `.gitignore`)
- **Проблема:** Содержит DATABASE_URL, JWT_SECRET, CHAT_SECRET_KEY, OPENROUTER_API_KEY.
- **Фикс:** `git rm --cached .env`, ротация всех секретов.

### C3. `.env.example` содержит реальные секреты
- **Файл:** `.env.example` (tracked)
- **Проблема:** Содержит `lavender:mypass` и `CHAT_SECRET_KEY=passphrasewhichneedstobe32bytes!`.
- **Фикс:** Заменить на плейсхолдеры.

### C4. HTTP upload без аутентификации
- **Файл:** `http_server.go:64-68, 137-141`
- **Проблема:** `/upload-avatar`, `/upload-image`, `/upload-file`, `/turn-credentials` — любой может загружать файлы и получать TURN credentials.
- **Фикс:** Добавить JWT middleware на HTTP сервер.

### C5. `/logs` без проверки admin
- **Файл:** `bot_commands.go:268`
- **Проблема:** `/logs` команда не проверяет `IsSuperAdmin`, любой пользователь может читать логи.
- **Фикс:** Добавить `IsSuperAdmin` проверку.

### C6. Критические SQL ошибки (DROP TABLE в продакшене)
- **Файл:** `db_hermes.go:152-154`
- **Проблема:** `DROP TABLE IF EXISTS ai_chat_messages CASCADE` выполняется при каждом старте сервера, удаляя данные.
- **Фикс:** Удалить DROP statements.

### C7. `query_database` tool — произвольный SQL
- **Файл:** `ai_tool_query_db.go:49-61`
- **Проблема:** Blacklist protection обходим. `RequiredRole()` не проверяется executor'ом.
- **Фикс:** Добавить table allowlist + read-only transaction + enforce role check.

## ВЫСОКИЙ ПРИОРИТЕТ (Should Fix)

### H1. N+1: IncrementUserChatListVersion в цикле
- **Файл:** `server_chats.go:315-317`
- **Проблема:** UPDATE в цикле по каждому participant. 100 участников = 100 запросов.
- **Фикс:** Батч-запрос `WHERE username = ANY($1::text[])`.

### H2. Goroutine leaks — RemoteAgentManager
- **Файл:** `hermes_remote_manager.go:353-392`
- **Проблема:** `processTaskQueue` и `healthCheckLoop` не останавливаются при shutdown.
- **Фикс:** Добавить context cancellation.

### H3. Race condition — RemoteAgentManager callbacks
- **Файл:** `hermes_remote_manager.go:206, 223`
- **Проблема:** `onResult`/`onStream` читаются без синхронизации.
- **Фикс:** sync.RWMutex или atomic pointer.

### H4. webFetchTool SSRF
- **Файл:** `ai_tool_web_fetch.go:36-69`
- **Проблема:** Фетчит любой URL, включая localhost, metadata endpoints.
- **Фикс:** Block private IPs, localhost, link-local, cloud metadata.

### H5. UpdatePassword игнорирует HashPassword error
- **Файл:** `db_users.go:164`
- **Проблема:** `h, _ := HashPassword(pass)` — пустой хеш при ошибке.
- **Фикс:** Return error.

### H6. MCP/subprocess provider — command injection
- **Файл:** `ai_provider_mcp.go:67`, `ai_provider_subprocess.go:68`
- **Проблема:** Command из agent config передаётся в exec без валидации.
- **Фикс:** Allowlist команд.

### H7. JSON injection в CreateGroupChat
- **Файл:** `server_chats.go:98-105`
- **Проблема:** Participants конкатенируются вручную вместо `json.Marshal`.
- **Фикс:** `json.Marshal(req.Participants)`.

### H8. Chat stream auth bypass (commented out)
- **Файл:** `server_chat.go:182-187`
- **Проблема:** Auth check закомментирован.
- **Фикс:** Раскомментировать.

### H9. Missing input validation
- **Файл:** `auth_service_v2.go:24-32`, `server_messages.go:368`
- **Проблема:** Нет лимитов длины на username, password, message text.
- **Фикс:** Добавить валидацию.

### H10. Missing auth checks на handlers
- **Файл:** `server_muted.go`, `server_favorites.go`, `server_drafts.go`
- **Проблема:** Handlers используют `req.UserId` от клиента вместо JWT context.
- **Фикс:** Всегда использовать `GetUserID(ctx)`.

### H11. Missing context timeouts на Firebase
- **Файл:** `server_push.go:84, 167, 381, 509`
- **Проблема:** `context.Background()` без timeout.
- **Фикс:** `context.WithTimeout(ctx, 10*time.Second)`.

### H12. Missing rows.Err() проверки (systemic, ~30+ мест)
- **Файл:** Все db_*.go файлы
- **Проблема:** После `rows.Next()` цикла нет `rows.Err()` проверки.
- **Фикс:** Добавить `if err := rows.Err(); err != nil { ... }`.

### H13. Scan errors игнорируются (systemic)
- **Файл:** db_chats.go, db_messages.go, db_users.go
- **Проблема:** `rows.Scan(...)` без проверки ошибки.
- **Фикс:** Проверять и логировать.

### H14. QueryRow error не возвращается
- **Файл:** `db_users.go:33-37, 39-43, 169-172, 175-178, 224-228`
- **Проблема:** Всегда return nil error.
- **Фикс:** Return scan error.

### H15. Encrypt errors игнорируются
- **Файл:** `server_push.go:312, 427`, `db_messages.go:163`
- **Проблема:** `enc, _ := encrypt(text)` — пустой результат при ошибке.
- **Фикс:** Log/return error.

### H16. JWT_SECRET без startup validation
- **Файл:** `main.go`
- **Проблема:** Сервер стартует без проверки наличия JWT_SECRET.
- **Фикс:** Fatal если JWT_SECRET отсутствует или < 32 bytes.

## ВЕРИФИКАЦИЯ

4. Для критических проблем: deploy на dev → проверка логов → deploy на prod
