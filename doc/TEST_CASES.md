## 1. OWL AI Чат

### OWL-01: Создание нового OWL чата
1. Открыть приложение → войти
2. Нажать [AI] кнопку рядом с [+]
3. В AIBottomSheet выбрать "Новый OWL чат"
4. **Ожидание:** Открывается OwlChatActivity с пустым списком сообщений

### OWL-02: Отправка сообщения и стриминг ответа
1. В OWL чате ввести "Привет, как дела?"
2. Нажать отправить
3. **Ожидание:**
   - Сообщение пользователя появляется сразу (не пропадает)
   - Появляется typing indicator (анимированные точки)
   - Ответ приходит стримингом (посимвольно)
   - После ответа typing indicator исчезает

### OWL-03: Анимация нового сообщения
1. Отправить сообщение в OWL чат
2. **Ожидание:** Новое сообщение появляется с fade-in + slide анимацией

### OWL-04: Множественные OWL чаты с нумерацией
1. Создать 3 новых OWL чата
2. **Ожидание:** В AIBottomSheet чаты называются "OWL чат", "OWL чат 2", "OWL чат 3"

### OWL-05: Long-press → PopupMenu
1. В AIBottomSheet сделать long-press на OWL чат
2. **Ожидание:** Появляется PopupMenu с "Настройки" и "Удалить"
3. Выбрать "Удалить" → чат удаляется

### OWL-06: Key/model banner в шапке
1. Открыть OWL чат
2. **Ожидание:** В тулбаре под названием видно "Общий ключ · 20 запросов/час" (или "Ваш ключ · {model}" если задан)

### OWL-07: Per-chat settings — задать свой ключ
1. В OWL чате нажать шестерёнку (или long-press → Настройки)
2. В OwlSettingsActivity задать свой API ключ и модель
3. Сохранить, вернуться в чат
4. **Ожидание:** Banner показывает "Ваш ключ · {model}"

## 2. Hermes Orchestrator Чат

### HERMES-01: Создание нового Hermes чата
1. В AIBottomSheet выбрать "Новый Hermes чат"
2. **Ожидание:** Открывается HermesChatActivity с агентами в тулбаре

### HERMES-02: Отправка сообщения и маршрутизация
1. В Hermes чате ввести "Напиши hello world на Python"
2. Нажать отправить
3. **Ожидание:**
   - Сообщение пользователя появляется
   - Typing indicator с именем агента (например "Developer")
   - Ответ приходит стримингом
   - Агент выбран автоматически (Developer для кода)

### HERMES-03: Множественные Hermes чаты
1. Создать 3 Hermes чата
2. **Ожидание:** В AIBottomSheet "Hermes чат", "Hermes чат 2", "Hermes чат 3"

### HERMES-04: Переключение агента
1. В Hermes чате нажать на чип другого агента (например "Designer")
2. Отправить сообщение
3. **Ожидание:** Активный агент выделен, ответ приходит от выбранного агента

### HERMES-05: Key/model banner
1. Открыть Hermes чат
2. **Ожидание:** Banner показывает ключ/модель как в OWL

## 3. Bot Commands

### CMD-01: /help
1. В OWL или Hermes чате ввести `/help`
2. **Ожидание:** Ответ со списком команд и описаниями

### CMD-02: /status
1. Ввести `/status`
2. **Ожидание:** Ответ с информацией о сервере (uptime, версия)

### CMD-03: /version
1. Ввести `/version`
2. **Ожидание:** Ответ с версией сервера (v1.1.1.14)

### CMD-04: /ai
1. Ввести `/ai расскажи шутку`
2. **Ожидание:** Ответ от OWL AI на запрос

### CMD-05: Неизвестная команда
1. Ввести `/unknowncommand`
2. **Ожидание:** Сообщение об ошибке или игнорирование

## 4. Rate Limiting

### RATE-01: Free tier лимит (20/час)
1. Использовать OWL чат с общим ключом
2. Отправить 20 сообщений в течение часа
3. Отправить 21-е сообщение
4. **Ожидание:** 21-е сообщение возвращает ошибку rate limit

### RATE-02: Custom key лимит (10/мин)
1. Задать свой ключ в настройках
2. Отправить 10 сообщений за минуту
3. 11-е сообщение
4. **Ожидание:** Ошибка rate limit

### RATE-03: Hermes rate limit
1. Проверить что Hermes чат тоже имеет rate limit
2. **Ожидание:** Лимиты работают аналогично OWL

## 6. Graceful Reconnect

### RECON-01: Восстановление после потери сети
1. Открыть любой чат
2. Выключить Wi-Fi/мобильные данные на 10 секунд
3. Включить обратно
4. **Ожидание:**
   - Статус "Подключение..." или аналогичный
   - Автоматическое переподключение без перезапуска
   - Сообщения не теряются

### RECON-02: Статус RECONNECTING
1. Во время разрыва сети проверить статус в тулбаре
2. **Ожидание:** Индикатор переподключения (текст или иконка)

### RECON-03: Keep-alive
1. Оставить приложение открытым на 5 минут без активности
2. **Ожидание:** Соединение не разрывается
